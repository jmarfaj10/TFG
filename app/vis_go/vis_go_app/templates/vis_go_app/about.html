About Vis GO

Vis GO is a web interface that lets you drive an autonomous robot using plain natural language. You describe where you want it to go, a vision-language model finds the target in the robot's camera, and the robot navigates to it on its own.

HOW IT WORKS

1

Prompt

You type a movement instruction in the VLM chat, such as "go to the red chair".

2

Detection

The vision-language model reads the camera frame, extracts the target object and returns its bounding box.

3

Goal

The depth image turns that box into a 3D goal (x, y, z) the navigation stack can reach.

4

Mission

The robot drives to the goal while you follow its telemetry live. The result is stored as a mission log.

WHAT YOU GET

Live robot camera

RGB and depth streams over WebSocket, switchable with a single toggle, so you always see what the robot sees.

Natural language chat

No coordinates, no joystick. Describe the destination and the model does the grounding for you.

Real-time telemetry

Position, orientation, active goal and mission state update as the robot moves.

Mission logs

Every mission is saved with its prompt, bounding box, goal, distance and duration, ready to review in Logs.
